# ReadAloud for iPhone Duo

**Planned App Store update: 25 October 2026**

ReadAloud turns documents into on-device speech. This upcoming update adapts the reading and listening experience to iPhone Duo, with layouts for six reading states and a continuous session that follows the user as the display changes.

## Six adaptive reading states

| State | ReadAloud experience |
|---|---|
| Book Fold | For supported documents, show Original Layout beside the synchronized Reading View. |
| Landscape | Keep Library navigation beside the active reader. |
| Portrait | Give the reader the full-height display with compact playback controls. |
| Closed | Continue the active reading session on the outer display. |
| Seated | Keep reading content above the display division and touch controls on the lower half. |
| Standing | Show a glanceable current sentence or short reading window with essential playback controls. |

## Keep your place as the display changes

The adaptation is designed to preserve the same document, current sentence, playback position and play state, selected voice, speed, repeat mode, and sleep timer when the user folds or rotates the device.

ReadAloud supports PDF, EPUB, Word, DRM-free Kindle, photos, web articles, and pasted text. Original Layout appears only for supported document sources.

## Privacy

ReadAloud uses on-device speech processing. Its current App Store privacy label indicates that the app does not collect data.
